# 🏷️ Jazz CI&D Organization Definitions and Standards

To keep our project management consistent, please use the following standardized branch names prefixed as "branch-label"/ before the name of each branch across all repositories in this organization:

| Label | Color | Description | When to Use |
| :--- | :---: | :--- | :--- |
| `🔴 bug` | `#d73a4a` | Something isn't working as intended. | Use when code behavior deviates from requirements. |
| `✨ feature` | `#a2eeef` | New feature request or enhancement. | Use for proposing or implementing new functionality. |
| `📚 documentation` | `#0075ca` | Improvements or additions to documentation. | Use for wikis, READMEs, or API reference changes. |
| `⚠️ critical` | `#ffffff` | Blocks release or breaks core functionality. | High priority; requires immediate eyes. |
| `🧹 chore` | `#cfd3d7` | Refactoring, build tools, or administrative updates. | No user-facing changes (e.g., updating dependencies). |

### 🔍 How to Search by Topic
